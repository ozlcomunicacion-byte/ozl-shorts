Uso de los Servicios de API de YouTube

OZL Comunicación utiliza los Servicios de API de YouTube a través de una herramienta interna (“OZL Shorts”) para subir y programar vídeos en su propio canal de YouTube. Al usar esta herramienta, se aplican las Condiciones del Servicio de YouTube (https://www.youtube.com/t/terms) y la Política de Privacidad de Google (https://policies.google.com/privacy).

Qué datos usamos: la herramienta solo accede, con autorización expresa mediante OAuth, a la cuenta de YouTube del propietario del canal, para subir vídeos y configurar su título, descripción, etiquetas, miniatura y fecha de publicación. No accede a datos de otros usuarios o canales, ni los recoge, almacena o comparte con terceros.

Cómo se almacenan: el token de autorización se guarda de forma local y cifrada en el equipo del propietario. No se almacenan datos de la API de YouTube en servidores externos.

Eliminación de datos y revocación del acceso: el acceso se puede revocar en cualquier momento desde la página de permisos de Google (https://myaccount.google.com/permissions). Al revocarlo, el token local queda inutilizado y se elimina del equipo en un plazo máximo de 7 días.

Uso de la API de TikTok

OZL Shorts utiliza la API de TikTok (Login Kit y Content Posting API) únicamente en nuestra cuenta propia de TikTok @datazozl, para publicar nuestros propios vídeos. Al usar esta herramienta, se aplican las Condiciones del Servicio de TikTok (https://www.tiktok.com/legal/terms-of-service) y su Política de Privacidad (https://www.tiktok.com/legal/privacy-policy).

Qué datos usamos: la herramienta solo accede, con autorización expresa mediante Login Kit, a la cuenta @datazozl, para publicar vídeos y configurar su descripción y opciones de publicación. No accede a datos de otros usuarios o cuentas, ni los recoge, almacena o comparte con terceros.

Cómo se almacenan: el token de acceso de TikTok se guarda de forma local en el equipo del propietario. No se almacenan datos de la API de TikTok en servidores externos.

Eliminación de datos y revocación del acceso: el acceso se puede revocar en cualquier momento desde los ajustes de la app de TikTok (Ajustes y privacidad > Seguridad > Apps y servicios). Al revocarlo, el token local queda inutilizado y se elimina del equipo en un plazo máximo de 7 días.
